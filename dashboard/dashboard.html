Run Breakdown

Auto-parsed from run logs. Simulator start → laps completed → what happened on each lap.

One block per simulator start, newest first. Kart and wall contacts come from AWSIM's own result-details.json, which only the evaluation bundle writes — a run started as bare make simulator-… has no such file, and those columns then read n/r (not recorded), never zero. Position while speed-limited is reconstructed from the lap crossings in Player.log, so it needs that file to have been copied out of the simulator container (tools/save_sim_artifacts.sh).
